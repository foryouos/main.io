瓶子的跋涉 — foryouos 的个人主页

瓶子的跋涉（foryouos.cn）是 foryouos 的个人站点，用来记录编程学习过程与生活片段。 内容围绕 C / C++ 语言基础、Linux 使用、网络编程（TCP/IP、Socket）与后台服务器方向展开， 也会写下一些日常思考与随笔。站名取意于漂流瓶：把当下写下的东西装进瓶子放进海里， 不知道会漂到哪里，但总归是在往前走。

本站页面为纯 HTML、CSS 与 JavaScript 编写，背景是手绘的 SVG 场景（日出与星海、海浪与漂流瓶）， 不依赖任何外部图片与视频资源，因此在弱网或资源失效时依旧可以完整访问。 页面提供昼夜两套配色：访客打开时会依据本地时间自动选择，也可以手动切换并记住选择。

关注方向

  • C 语言与 C++：语法基础、指针与内存管理、面向对象与标准库
  • Linux 与网络编程：系统调用、TCP/IP 协议、Socket 编程、并发与 IO 模型
  • 后台服务器开发：进程与线程、服务端架构、性能与调试
  • 数据结构与算法：基础数据结构、常见算法题的思路整理
  • 投资与量化分析：指数基金、ETF 持仓穿透与组合收益回顾（业余兴趣）
